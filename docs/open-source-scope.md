# 公开范围与整理记录

仓库定位是设备适配方法与参考实现，默认型号保护仍然保留。本次整理不修改已安装应用的配对和偏好设置，不删除浏览器正在使用的扩展源目录。

| 内容 | 处理及原因 |
| --- | --- |
| 原生菜单栏、扩展、逻辑检查 | 保留，可复现最终实现 |
| 只读 DDC 探测、可恢复亮度试验 | 保留，支持他人验证硬件 |
| HDR 预设调查 | 整理成脱敏的方法与结论，保留失败路径经验 |
| 原始诊断 JSON、安装/运行/验收报告 | 删除，含本机状态、路径或实例标识，无需逐份公开 |
| 未采用的 `0xDC` 写入试验、MonitorPanel/HDR 探测 | 删除，避免被误当成通用预设切换功能 |
| `.build/`、`build/`、Python 缓存、`.DS_Store` | 清理，可重新生成并已加入忽略规则 |
| 图标源图、生成提示词 | 保留，供复用与构建 |
| 扩展公钥、固定 ID | 保留，是公开标识，不是认证凭据 |
| 配对令牌、应用偏好、GitHub 凭据 | 不纳入仓库，只保存在各自本机存储 |

`local/` 与 `diagnostics/` 被 Git 忽略，供后续本机报告使用。忽略规则不等于脱敏：强制添加、分享终端输出或附加报告前，仍要检查内容。
